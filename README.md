# 友カフェちゃんBOT

![友カフェちゃん](https://i.imgur.com/Sq5nZnS.jpeg)

友カフェちゃんBOTは、Discord サーバー「友カフェ」で雑談、コーヒー豆集め、アイテム収集、メモ管理を楽しむためのカフェ店員 BOT です。コマンドの先頭には、半角 `!` または全角 `！` を付けます。

## はじめかた

サーバーに参加すると、通常は自動で登録されます。初回登録時にはウェルカムコーヒー 1 個とコーヒー豆 10 豆が届きます。

自動登録されていない場合は、スラッシュコマンドの `/register` を使ってください。以後、豆を受け取ったり、アイテムを確認したりできます。

## みんなが使えるコマンド

| やりたいこと | コマンド | 説明 |
| --- | --- | --- |
| 今日のおすすめを聞く | `！メニュー` / `!menu` / `/menu` | ドリンクとデザートをランダムで紹介します |
| 雑談の話題を出す | `！話題` / `!wadai` / `/wadai` | 話題をランダムで出します |
| 深夜向けの話題 | `！深夜` / `!shinya` / `/shinya` | ちょっとカオスな深夜の話題です |
| 今日の豆を受け取る | `！日給` / `!daily` / `/daily` | 24 時間に 1 回、10〜20 豆を受け取れます |
| 豆を確認する | `！残高` / `!balance` | いま持っているコーヒー豆を表示します |
| 持ち物を見る | `！インベントリ` / `!inventory` | 所持アイテムをカード形式で表示します |
| メモを追加する | `！メモ追加 買い物` | 自分用のメモを追加します。カンマや空白で複数追加もできます |
| メモを見る・完了にする | `！メモ` | 数字リアクションで完了にできます。ページ移動は 👈 / 👉、閉じるには ❌ |
| メモを削除する | `！メモ削除` | 数字リアクションで対象メモを削除します |
| BOT の応答確認 | `!ping` / `/ping` | PONG が返ります |

メモ画面は開いた本人だけが操作できます。操作できるのは 5 分間です。

## コーヒー豆とアイテム

- コーヒー豆は BOT 内の通貨です。毎日の日給やイベント報酬などで増えます。
- アイテムはインベントリで確認できます。ウェルカムコーヒーは戦闘で HP を回復できるアイテムです。
- ショップがチャンネルに出ているときは、カードの「買う」ボタンで購入できます。残高が足りない場合は購入できません。

## 戦闘について

カフェには、ときどきモンスターが現れます。戦闘では「こうげき」「アイテム」「しらべる」を使います。

- こうげき: 相手にダメージを与えます。倒せなければ反撃を受けます。
- アイテム: 回復や、相手に有効なアイテムを使います。
- しらべる: 1 回だけ使えます。相手のヒントを得て、次の攻撃が少し強くなります。
- 相手が大きな行動をしそうなときは、普段と違う選択肢が出ます。表示された説明を読んで選んでください。

現在、`！戦闘` / `!battle` は BOT 管理者が動作確認に使うコマンドです。一般向けの戦闘開始はサーバーのお知らせに従ってください。

## BOT 管理者向け

管理者ロールを持つ人は、アイテム作成・ショップ表示・豆やアイテムの付与を行えます。

| コマンド | 例 | 内容 |
| --- | --- | --- |
| `!citem` | `!citem coffee_latte ラテ 説明 ノーマル https://example.com/a.png 10` | アイテムを作成 |
| `!cshop` | `!cshop coffee_latte` / `!cshop all` | ショップカードを表示 |
| `!gbeans` | `!gbeans @ユーザー 10` | 豆を付与 |
| `!gitem` | `!gitem @ユーザー coffee_latte` | アイテムを 1 個付与 |
| `!guide` | `!guide` | サーバー向け案内を投稿 |
| `!battle` | `!battle` | テスト用戦闘を開始 |

管理画面や BOT の設定・運用を行う開発者は、[開発者ドキュメント](docs/README.md) を参照してください。

## 困ったとき

- 日給が受け取れない: 前回の受け取りから 24 時間待ってください。
- コマンドが反応しない: `!` または `！` が先頭にあるか、コマンド名の間に余計な文字がないか確認してください。
- メモを操作できない: メモを開いた本人だけが操作できます。5 分経過後はもう一度 `！メモ` を実行してください。
- 登録されていないと言われる: `/register` を実行してください。
