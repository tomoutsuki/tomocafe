## 読み方

変更前は、まずアーキテクチャとドメインルールを読み、対象の専門文書を読んでください。実装上の事実と「今後も守るべきルール」は区別しています。現在のコードがまだ満たしていないルールや、移行上のリスクは各文書の **現状の注意点** に明記しています。
